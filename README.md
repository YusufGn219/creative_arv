# ✍️ Creative Arv

A quality-focused deep content platform for developers, 
writers and academics.

## 📌 Overview

A content platform that goes beyond standard publishing tools 
with an approved author system, article series, forum discussions 
and moderation tools. Built for long-form, high-quality content.

## ✅ Features

- ✍️ Content system — articles, series (chapter-based content), version history
- 🔐 Approved author system — application process as quality filter
- 💬 Forums — topic-based and independent discussions
- 🗨️ Comment system — nested replies, soft delete, Generic FK (article + forum)
- 👥 Multi-author support — co-authorship + role management
- 📊 Reading statistics
- 🛡️ Moderation system — content, user and IP bans
- 🔑 JWT authentication — access + refresh token

## 🏗️ Architecture

**Backend:** Django REST Framework, PostgreSQL  
**Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS v4, shadcn/ui  
**Design:** 3-column layout, dark purple/black theme, Playfair Display
